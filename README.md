An original canvas runner: you are the turkey, the farmer is behind you with a carving knife, and the forest line — 1,200 metres of ovens, sailing knives, rolling barrels and spring-loaded hat traps away — is a presidential pardon. Jump and flap, duck the blades, gobble-dash through brick ovens, chain golden corn into combos, and don't let his hand close on your tail feathers.

## Play it

Open `game/index.html` in a desktop browser — no build, no network, everything is drawn and synthesized in code.

- **SPACE / W / ↑** jump, again mid-air to flap · **↓ / S** duck · **D** gobble-dash
- **P** pause · **M** mute · **R** restart

## Run the hand-in

```sh
node main.ts   # copies game/ + screenshots/ to /output and writes dossier.json
```
